# Gate: Architecture (🔒 human approval required)

- [ ] Context + current system described (or Unknown marked with owner to confirm)
- [ ] ≥2 options considered where trade-off exists (or justification for single option)
- [ ] Proposed solution explicit; human decision recorded (approved option + approver + date)
- [ ] API changes identified (or "None because …")
- [ ] Data changes identified incl. migration plan (or "None because …")
- [ ] Dependencies identified (services, libs, team)
- [ ] Failure handling described (retry, timeout, idempotency, rollback)
- [ ] Security considered (auth, input, secrets, PII — even if "no change because …")
- [ ] Observability planned (logs, metrics, alerts)
- [ ] Trade-offs + Risks documented
- [ ] Task breakdown sequenced with acceptance criteria + test requirements
