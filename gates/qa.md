- [ ] Edge cases tested with evidence
- [ ] Failure scenario tested (invalid input / auth / network / timeout — at least one)
- [ ] Acceptance criteria mapped to test cases (traceability)
- [ ] Defects filed with steps/expected/actual/severity/evidence (or "No defects")
- [ ] Not-tested section exists (scope + reason)
- [ ] Blocking defects = 0 before review
