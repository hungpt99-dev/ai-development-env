# Gate: Requirement (🔒 human approval required)

All boxes must be checked before architecture starts. AI self-checks; human signs.

- [ ] Problem + Goal + Scope stated; out-of-scope listed
- [ ] Actors identified
- [ ] Functional requirements explicit and numbered (FR-1, FR-2, …)
- [ ] Business rules explicit (BR-1, …)
- [ ] Acceptance criteria testable (Given/When/Then or equivalent)
- [ ] Edge cases listed (or "None identified because …")
- [ ] Ambiguity section exists: Assumptions / Open questions (empty = `None`, not omitted)
- [ ] Sources quoted (stakeholder, ticket, doc link)
- [ ] Decision log block present (Decided / Proposed / Assumption / Open Q / Trade-off)
- [ ] No technical solutioning leaked into requirement
