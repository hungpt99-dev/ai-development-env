# Gate: Release

- [ ] CI green: build + lint + tests + secret-scan
- [ ] Changelog + release notes updated
- [ ] Migrations reversible or backup verified
- [ ] Secrets via manager; no secrets in image/repo
- [ ] Rollback plan documented (command or steps)
- [ ] Observability: logs/metrics/alerts for new behavior
- [ ] Smoke test defined + result recorded
- [ ] Post-release monitoring owner + window assigned
